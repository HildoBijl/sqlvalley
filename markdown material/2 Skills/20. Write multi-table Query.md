# Theory(todo)
Often you need to combine multiple tables to set up a proper filtering. You then have two options: either join the tables, and apply the corresponding filtering, or use a subquery on one table and apply `IN, NOT IN, EXISTS` and `NOT EXISTS` on this subquery. Which one works better depends on the situation and on personal preferences. In very special circumstances, you may also have to combine tables using `UNION, INTERSECT` and `EXCEPT`.

2. Find the first name and last name of unverified accounts who appear as buyers, but not as vendors in transactions
```sql
SELECT first_name, last_name
FROM accounts a
WHERE a.email_verified = FALSE
AND a.username IN (
	SELECT buyer
	FROM transactions
	)
	AND a. username NOT IN (
		SELECT vendor
		FROM transactions
		)
```

3. Retrieve the usernames of all users who have bought one or more products from the 'Fine Art' category at any point in time, that also appear as owners of products categorized as "Designer Fashion".
```sql
SELECT DISTINCT buyer
FROM transactions
WHERE prod_id IN (
	SELECT p_id
	FROM products
	WHERE category = 'Fine Art'
)
INTERSECT
SELECT DISTINCT owned_by
FROM products
WHERE category = 'Designer Fashion'
```

### 2. A student wants to know which students involved in extracurricular activities are at Stanford University.
Task: Write an SQL query to get Student Name, University and Activity.
#### Solution:
```sql
SELECT Students.Name, University.Name AS University, Extracurricular.Activity  
 FROM Students  
 JOIN University ON Students.U_id = University.U_id  
 JOIN Extracurricular ON Students.S_id = Extracurricular.S_id  
 WHERE University.Name = 'Stanford University';
```
#### Hint 1:
JOIN Students → University and Students → Extracurricular.
#### Hint 2:
Filter on University.Name = 'Stanford University'.

### 3. A student is curious which students scored above 5 in their courses and are from MIT.
Task: Write an SQL query to get Student Name, Course Name and Grade.
#### Solution:
```sql
SELECT Students.Name, Courses.Name AS Course, Grades.Grades  
 FROM Students  
 JOIN Grades ON Students.S_id = Grades.S_id  
 JOIN Courses ON Grades.C_id = Courses.C_id  
 JOIN University ON Students.U_id = University.U_id  
 WHERE Grades.Grades > 5 AND University.Name = 'MIT';
```
#### Hint 1: 
Use multiple joins from Students to University, Courses, and Grades.
#### Hint 2:
Apply filters on grade and university.

### 4. A student wants to connect with students in extracurriculars who also passed Chemistry.
Task: Write an SQL query to retrieve Name, Activity and Course Name where Course is 'Organic Chemistry' and Grade >= 6.
### Solution:
```sql
SELECT Students.Name, Extracurricular.Activity, Courses.Name AS Course  
 FROM Students  
 JOIN Grades ON Students.S_id = Grades.S_id  
 JOIN Courses ON Grades.C_id = Courses.C_id  
 JOIN Extracurricular ON Students.S_id = Extracurricular.S_id  
 WHERE Courses.Name = 'Organic Chemistry' AND Grades.Grades >= 6;
```
#### Hint 1:
JOIN Students with Grades, Courses, and Extracurricular.
#### Hint 2:
Filter on `Courses.Name` and passing grade.

### List the customers (id and name) who bought something on some date that was not on their shopping list for that date.
- `LEFT JOIN` is used to try and find a matching shopping list entry for each purchase.
- The `WHERE sl.cID IS NULL` filters to **only those purchases** that **had no matching shopping list** entry — meaning the customer bought something they didn’t plan for
- We then join with `customer` to get their name.
- `DISTINCT` ensures each customer is listed once even if they did this multiple times.
```sql
SELECT DISTINCT c.cID, c.cName
FROM purchase p
LEFT JOIN shoppinglist sl 
  ON p.cID = sl.cID 
  AND p.pID = sl.pID 
  AND p.date = sl.date
JOIN customer c 
  ON p.cID = c.cID
WHERE sl.cID IS NULL;
```

- For each `purchase`, check if there **does not exist** a matching row in `shoppinglist`.
- If not, then the product was **not planned** for that date → this customer qualifies.
- `DISTINCT` avoids duplicates.
```sql
SELECT DISTINCT c.cID, c.cName
FROM purchase p
JOIN customer c ON p.cID = c.cID
WHERE NOT EXISTS (
    SELECT 1
    FROM shoppinglist sl
    WHERE sl.cID = p.cID 
      AND sl.pID = p.pID 
      AND sl.date = p.date
);
```

- Find all `(cID, pID, date)` triplets that appear in `purchase` but **not** in `shoppinglist`.
- Then, fetch the `cName` from `customer`.
```sql
SELECT DISTINCT p.cID, c.cName
FROM (
    SELECT cID, pID, date
    FROM purchase
    EXCEPT
    SELECT cID, pID, date
    FROM shoppinglist
) AS unmatched
JOIN customer c ON unmatched.cID = c.cID;
```
