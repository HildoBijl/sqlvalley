Retrieve the names of employees who appear as validators in transactions where the customer ID is the same as the vendor ID.
```sql
SELECT name
FROM employees
WHERE e_id IN
	(SELECT validator_id AS e_id
	FROM transactions
	WHERE c_id = v_id)
```

Retrieve all transactions that occurred before the corresponding vendor’s registration date.
```sql
SELECT t.v_id, t.c_id, t.p_id, t.date_time, t.amount
FROM transactions t
WHERE t.date_time < (
    SELECT v.registration_date
    FROM vendors v
    WHERE v.v_id = t.v_id
);
```

# Example Exercises
### Find the names of all employees who earn more than every employee of Small Bank Corporation.
```sql
SELECT w.person_name
FROM works w
WHERE w.salary > ALL (
    SELECT salary
    FROM works
    WHERE company_name = 'Small Bank Corporation'
);
```
