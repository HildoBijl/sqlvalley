# Theory
When there are multiple linked tables, you can join them together. SQL has a large variety of tools to do so. You can do so using a simple `WHERE` statement, which gives all combinations of rows. These can then of course be filtered. The short-cut is the `JOIN`. There is either the `NATURAL JOIN` that compares equally named attributes, or the `JOIN` itself which can specify the join conditions through `"ON"`. On top of that, there is a distinction between the `INNER JOIN` and the `OUTER JOIN`. 

*(This skill does not involve complicated filtering to be done on the resulting joins yet. The focus is on joining tables. Basic filters can be included.)*

## Preliminary
 

Retrieve all transactions that occurred before the vendor involved was officially registered.
```sql
SELECT t.vendor_id, t.buyer_id, t.p_id, t.date_time, t.amount
FROM transactions t
JOIN accounts v ON t.vendor_id = v.vendor_id
WHERE t.date_time < v.registration_date;
```

Retrieve the names of accounts and customers whose accounts were created on the same date and participated in the same transaction.
```sql
SELECT vendor.name, customer.name
FROM transactions AS t
JOIN accounts AS vendor ON vendor.id = t.vendor_id 
JOIN accounts AS accounts ON accounts.id = t.buyer_id
WHERE vendor.created_at = accounts.created_at
```

Retrieve the product name and the amount it was sold for for all transactions where the product was sold by someone other than its owner.
```sql
SELECT t.amount, p.name
FROM transactions t
JOIN products p ON t.p_id = p.p_id
WHERE t.vendor_id != p.owner_id;
```

# Examples
### Find the names of all employees who work for at least two (different) companies.
#### Solution
```sql
SELECT DISTINCT w1.person_name
FROM works w1
JOIN works w2
  ON w1.person_name = w2.person_name
 AND w1.company_name <> w2.company_name;
```

## Tushar Exercises
1. Use the `JOIN` clause to connect related tables.
 2. Always specify `ON` conditions using foreign keys like `S_id`, `U_id`, or `buyer_id`.
 3. Choose `INNER JOIN` to match records, and use `LEFT JOIN` or `RIGHT JOIN` when partial matches are acceptable.

### 1. A student wants to know which university students go to.
Task: Write an SQL query to retrieve Name and University Name from the Students and University tables.
#### Solution:
```sql
SELECT Students.Name, University.Name AS University  
 FROM Students  
 JOIN University ON Students.U_id = University.U_id;
```
#### Hint 1:
Use the Students and University tables.
#### Hint 2:
Use `INNER JOIN` on `U_id` column.
___
### 2. A student wants to find out the activities done by peers in their university.
Task: Write an SQL query to retrieve Student Name and Activity by joining Students and Extracurricular tables.
#### Solution:
```sql
SELECT Students.Name, Extracurricular.Activity  
 FROM Students  
 JOIN Extracurricular ON Students.S_id = Extracurricular.S_id;
```
#### Hint 1:
Use JOIN on Students and Extracurricular.
#### Hint 2:
Join using S_id.
___
### 3. A student wants to see how classmates performed in different courses.
Task: Write an SQL query to get Student Name, Course Name and Grade.
#### Solution:
```sql
SELECT Students.Name, Courses.Name AS Course, Grades.Grades  
 FROM Students  
 JOIN Grades ON Students.S_id = Grades.S_id  
 JOIN Courses ON Grades.buyer_id = Courses.buyer_id;
```
#### Hint 1:
Use two JOINs to link Grades with Students and Courses.
#### Hint 2:
Filter can be added later for specific results.
___
### 4. A student wants to explore university-wise performance in a course.
Task: Write an SQL query to get University Name, Student Name and Grade.
%% multiple joins, too complex %%
#### Solution:
```sql
SELECT University.Name AS University, Students.Name, Grades.Grades  
 FROM Grades  
 JOIN Students ON Grades.S_id = Students.S_id  
 JOIN University ON Students.U_id = University.U_id;
```
#### Hint 1:
Join Grades → Students → University.
#### Hint 2:
Use Students.U_id to join University.
