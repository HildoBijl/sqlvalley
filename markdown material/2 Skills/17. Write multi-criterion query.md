# Theory
In practice you often need to write queries that involve complex projections, filters with multiple conditions, and potentially sorting. In this skill we practice exactly that, combining these separate parts and making sure we don't mix them up along the way. Optionally, you can use the `DISTINCT` addition to obtain unique rows. (This only involves single-table queries and not multi-table queries. Exercises usually contain (on top of multi-condition filtering) either arithmetic-based columns or sorting/limiting, and not both, since in practice you rarely need all tools at the same time.)

## Preliminary

Retrieve the first 10 employees whose start date falls between January 1 and September 1 of 2025, sorted by start date.
```sql
SELECT e_id, start_date, position, perf_score
FROM emp_data
WHERE start_date BETWEEN '2025-01-01' AND '2025-09-01'
ORDER BY start_date
LIMIT 10
```

Retrieve the employee ID, status, and monthly salary of employees whose status contains “sick” and whose monthly salary is either above 10,000 or below 1,000.
```sql
SELECT e_id, status, salary/12 AS monthly_salary
FROM emp_data
WHERE status LIKE '%sick%' AND (salary/12 > 10000 OR salary/12 < 1000);
```

Retrieve the names of all departments except HR, Customer Support, Public Relations, and Tech Support, and list their budget per employee, sorted from highest to lowest.
```sql
SELECT d_name AS name,
       budget / nr_employees AS expenditure
FROM departments
WHERE d_name NOT IN ('Human Resources', 'Customer Support', 'Public Relations', 'Tech Support')
ORDER BY expenditure DESC;
```
