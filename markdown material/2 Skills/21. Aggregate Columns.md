# Theory(todo)
To aggregate columns in SQL, use the aggregation functions `MIN, MAX, AVG, SUM, COUNT` and so forth, for numerical values. Note that because multiple rows get merged, you cannot pick other columns. You can do this for the whole table, or you can use the `GROUP BY` to make groups. In this case, you can pick the grouped-by columns.

## Preliminary

Retrieve the total revenue for each fiscal year.
```sql
SELECT fiscal_year, SUM(revenue)
FROM quarterly_performance
GROUP BY fiscal_year;
```

Retrieve the average growth rate for each quarter of every fiscal year.
```sql
SELECT fiscal_year, quarter, AVG(growth_rate)
FROM quarterly_performance
GROUP BY fiscal_year, quarter
```

Retrieve the maximum and minimum revenue for each fiscal year.
```sql
SELECT fiscal_year, MAX(revenue) AS max_revenue, MIN(revenue) AS min_revenue
FROM quarterly_performance
GROUP BY fiscal_year;
```

Retrieve the total expenses for each department.
```sql
SELECT d_id, SUM(amount) AS total_expenses
FROM expenses
GROUP BY d_id
```

Count the number of quarters with negative growth.
```sql
SELECT COUNT(*) AS high_growth_quarters
FROM quarterly_performance
WHERE growth_rate < 0.0;
```
