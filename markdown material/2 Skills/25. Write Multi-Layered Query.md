# Theory(todo)
Sometimes you need to write queries having multiple layers. Key is to keep things structured. One way to do this is to write your own temporary queries, defining them with `WITH` (making a Common Table Expression (CTE)). However, if you want to use parameters of outer queries inside inner queries, then this isn't possible, and multiple queries need to be nested inside each other. Often multiple solutions are possible, so it's up to you to find one that not only works but is also easy enough to understand. This reduces potential oversights and errors. (Subqueries may require also a simple aggregation like finding a minimum or maximum value, or using some arithmetic on columns values.)

 ## Mock exercises
1. Retrieve the id, budget, and total amount spent of all the departments whose total recorded expenses never exceeded their allocated budget
```sql
WITH dept_expenses AS (
	SELECT 
		d_id, SUM(amount) AS total_spent
	FROM expenses
	GROUP BY d_id
),
dept_budget AS (
	SELECT d_id, budget
	FROM departments
)
SELECT b.d_id, b.budget, e.total_spent
FROM dept_budget b
JOIN dept_expenses e 
	ON b.d_id = e.d_id
WHERE e.total_spent <= b.budget
```


2. Identify the username, amount spent and amount earned, for all users whose total revenue as vendor exceeds their total spending as buyer
```sql
WITH vendor_totals AS (
    SELECT vendor AS username, SUM(price) AS earned
    FROM transactions
    GROUP BY vendor
),
buyer_totals AS (
    SELECT buyer AS username, SUM(price) AS spent
    FROM transactions
    GROUP BY buyer
)
SELECT v.username,
       v.earned,
       b.spent
FROM vendor_totals v
JOIN buyer_totals b
    ON v.username = b.username
WHERE v.earned > b.spent;
```

3. Retrieve the name of  the products owned by users who never appear as buyers in any transaction
```sql
WITH buyers AS (
	SELECT DISTINCT buyer
	FROM transactions
),
eligible_owners AS (
	SELECT username
	FROM accounts
	WHERE username NOT IN (
		SELECT buyer
		FROM buyers
	)
)
SELECT p.name
FROM products p
JOIN eligible_owners o
	ON p.owned_by = o.username
```

4. Return the full records of the employees whose current salary is the highest they have ever had across all their contracts TOO EASY
```sql
WITH highest_contract AS (
	SELECT e_id, MAX(salary) AS max_salary
	FROM contracts
	GROUP BY e_id
)
SELECT e.*
FROM employees e
JOIN highest_contract h
	ON e.e_id = h.e_id
WHERE e.current_salary > h.max_salary
```

 ### Find all accounts with the maximum balance
```sql
WITH max_balance (value) AS (  
		SELECT MAX (balance)  
		FROM account )  
SELECT account_number  
FROM account, max_balance  
WHERE account.balance = max_balance.value
```

#### 1. It is December 12, 2024. Robert Brijder (id 123456) wants to go shopping in his home city of Eindhoven and creates a shopping list (for that date). List all the stores (id and name) in Eindhoven that have sufficient stock of everything on the shopping list (on that date).
```sql
SELECT sID, sName  
FROM store  
WHERE city='Eindhoven' AND sID NOT IN (  
  SELECT i.sID  
  FROM inventory AS i, shoppinglist AS s  
  WHERE i.pID=s.pID AND i.quantity<s.quantity AND i.date=s.date AND s.date='December 12, 2024' and s.cID='123456'  
) AND NOT EXISTS (  
  SELECT s.pID  
  FROM shoppinglist AS s  
  WHERE s.cID='123456' AND s.date='December 12, 2024' AND s.pID NOT IN (  
    SELECT i.PID  
    FROM inventory AS i  
    WHERE i.date='December 12, 2024' AND s.sID = store.sID  
));
```

```sql
SELECT s.sID, s.sName
FROM store s
WHERE s.city = 'Eindhoven'
  AND NOT EXISTS (
    SELECT sl.pID
    FROM shoppinglist sl
    WHERE sl.cID = 123456
    AND sl.date = '2024-12-12'
    AND sl.pID NOT IN (
      SELECT i.pID
      FROM inventory i
      WHERE i.sID = s.sID
      AND i.date = sl.date
      AND i.quantity >= sl.quantity
    )
  );
```

#### 2. List the shop(s) (id and name) with the largest inventory of 'Kelloggs Rice Crispies' on December 10, 2024. (We have omitted the ' that belongs in the name Kellogg's to avoid problems with quotes. You may assume that there is only one product named 'Kelloggs Rice Crispies' but this is the _name_ of the product and not the _product id_.)
```sql
SELECT cID, cName  
FROM customer  
WHERE cID NOT IN (  
  SELECT cID  
  FROM purchase AS P  
  WHERE (cID, pID, date) NOT IN (  
    SELECT cID, pID, date  
    FROM shoppinglist  
));
```
