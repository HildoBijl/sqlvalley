# Theory(old)
When receiving a table filled with data from a query, we might want to order the rows in a certain way. For instance alphabetically by name, sorted by number of employees, or similar. How can we use SQL to sort rows in a table?

## Sort on a single column

To instruct SQL to sort rows, we add an `ORDER BY` command to the end of the query, followed by the name of the column by which it should be ordered. By adding the `ASC` (ascending) or `DESC` (descending) classifiers, we indicate the sorting direction.

``` sql
SELECT *
FROM companies
ORDER BY name DESC
```
## Sort based on multiple columns

If the sorting column has many equal values, it is helpful to add a second (or even a third and fourth) sorting column. We can do this by giving a list of column sortings, separated by commas. When rows have the same value within the first column, then the second column is used for comparison, and then the third, and so forth.
```sql
SELECT *
FROM companies
ORDER BY
country ASC,
name DESC
```
## Limit the number of rows
If not the whole table is needed, but only the first few rows, then we can limit the number of rows that are given. To do so, we add a `LIMIT` command after the `ORDER BY` command and specify how many rows we need.
```sql
SELECT *
FROM companies
ORDER BY name DESC
LIMIT 2
```

It is also possible to first skip a few rows. This is done through the `OFFSET` command. It specifies how many rows should first be skipped.
```sql
SELECT *
FROM companies
ORDER BY name DESC
LIMIT 2 OFFSET 1
```

Though most database management systems use the `LIMIT` and `OFFSET` commands, there are a few DBMs that do not stick to this convention. If the usual commands do not work, even on simple queries, check out the specifications for your own DBM.
## Deal with NULL values
When sorting, NULL values are always considered "larger" than any other values. So when sorting ascending they'll come last, and when sorting descending they'll come first. If this is not what we want, we could manually specify where we want the NULL values by adding `NULLS FIRST` or `NULLS LAST`. This is optional and can be done separately per sorting column.
```sql
SELECT *
FROM companies
ORDER BY country ASC NULLS FIRST
```
# Theory(new)
We know how in SQL we can retrieve an entire table. The rows then usually appear in the order in which they are added. If we want a different order, we can **sort** the table. Let's check out how this works.

## Sort on a single column
To sort your results, add an `ORDER BY` clause to the end of the query and specify the column to sort by. Optionally, add `ASC` (ascending, default) or `DESC` (descending) to choose the sorting direction.
```sql
SELECT *
FROM companies
ORDER BY company_name DESC;
```

|id|company_name|country|founded_year|num_employees|industry|
|---|---|---|---|---|---|
|8|TikTok|United States|2,016|150,000|Social Media|
|5|PwC|Netherlands|1,998|328,000|Consulting|
|2|Meta|United States|2,004|77,000|Social Media|
|1|LinkedIn|United States|2,003|20,000|Social Media|
|4|KPMG|Netherlands|1,987|236,000|Consulting|
|3|ING|Netherlands|1,991|57,000|Banking|

The exact sorting method depends on the **data type**. For numbers, we sort by magnitude. For text, we sort alphabetically. For dates/times, we sort by which date/time is earlier or later.

## Sort based on multiple columns
When the first column contains sorting ties, then you can add additional sorting attributes separated by commas. Only when the first attribute is equal, will SQL compare the second attribute to determine the order. And then a third attribute, if given, and so forth.

```sql
SELECT *
FROM companies
ORDER BY
country ASC,
name DESC;
```

## Limit the number of rows
To limit the number of rows that are returned, add a `LIMIT` clause, followed by how many rows you want to be returned.

```sql
SELECT *
FROM companies
ORDER BY name DESC
LIMIT 2;
```
Combine `LIMIT` with `OFFSET` to skip a number of rows before returning results.


```sql
SELECT *
FROM companies
ORDER BY name DESC
LIMIT 2 OFFSET 1;
```

Most database engines support `LIMIT` and `OFFSET`, but a few use alternative keywords. If these clauses do not work in your DBMS, check its documentation for the preferred syntax.

## Deal with NULL values

NULLs are treated as the **largest** possible values when sorting. They appear last with ascending order and first with descending order. If you want this to be different, you can override this behaviour with `NULLS FIRST` or `NULLS LAST`, specified per sorting attribute.

## Preliminary
1. Retrieve all employees, sorted first by performance score ascending, and for equal scores, by salary descending.
```sql
SELECT *
FROM emp_data
ORDER BY perf_score ASC, salary DESC;  
```

Retrieve 5 departments with the smallest budgets, skipping the first 3.
```sql
SELECT *
FROM departments
ORDER BY budget ASC
LIMIT 5 OFFSET 3
```

Retrieve the data of all employees, ordered by end date. Put everyone with an unlimited contract at the end
```sql
SELECT *
FROM emp_data
ORDER BY end_date ASC NULLS LAST;
```

### 1. A student wants to shortlist peers for a project based on their YearOfBirth, starting from the youngest.
Task: Write an SQL query to retrieve the `Name` and `YearOfBirth` from the `Students` table sorted in ascending order by `YearOfBirth`.
#### Solution:  
 ```sql 
 SELECT Name, YearOfBirth 
 FROM Students 
 ORDER BY YearOfBirth ASC;
 ```
#### Hint 1: 
Use the Students table
#### Hint 2:
Use `ORDER BY` with `ASC` to sort `YearOfBirths` in increasing order

### 2. A student is trying to see which companies have the most employees to prioritize top firms first
 Task: Write an SQL query to retrieve the Com_name  and Num_employees from the Companies table, sorted by Num_employees in descending order.
#### Solution
```sql
SELECT Com_name , Num_employees 
FROM Companies 
ORDER BY Num_employees DESC;
```
#### Hint 1:
Use the `Companies` table
#### Hint 2:
Use `ORDER BY` with `DESC` for descending sorting

### 3. A student wants to send a survey starting with classmates whose names come first alphabetically.
Task: Write an SQL query to retrieve Name and Email from Students table sorted alphabetically by Name.
#### Solution:
```sql
SELECT Name, Email 
FROM Students 
ORDER BY Name ASC;
```
#### Hint 1:
Use the Students table
#### Hint 2: 
Use ORDER BY with Name column
