# Drawing

React components for figures combining HTML elements and SVG shapes. `Figure` provides the container; `Drawing` adds coordinates, sizing, and layers for components such as `Element`, `Curve`, and `Rectangle`. `Glyph` displays the bundled database, server, and user illustrations.

Import components, their types, and drawing hooks from `@sqlvalley/drawing`.

```tsx
import { Drawing, Rectangle } from '@sqlvalley/drawing'
```

This package contains rendering tools only; application layout and theme belong to the application.
